# Historical engineering records

This directory holds corrected, evidence-backed accounts of compatibility work whose early conclusions still appear in chronological release notes or closed tickets.

- [`a1181-port-lessons.md`](a1181-port-lessons.md) records how the MacBook1,1 port moved from an “impossible” verdict to a working physical Omarchy desktop, what the lost terminal sessions taught us about evidence continuity, and which installer and hardware gates remain.
- [`macbook-convergence-20260905.md`](macbook-convergence-20260905.md) records the live upstream merge, restoration of dormant upstream components, actual 1 GB memory baseline, and recovery of compatibility package recipes.
- [`macbook-lite-launchers-20260906.md`](macbook-lite-launchers-20260906.md) records the missing-installer and screensaver repairs, physical validation, package recovery hashes, and remaining Codex/notification limitations.

These files explain why the current code and runbooks have their safeguards. They are not substitutes for the current installation procedure or acceptance checklist.
